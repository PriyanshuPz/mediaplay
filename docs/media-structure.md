## Media Folder Structure

This is very important. Scanner depends on this structure.

For Movies folder you can name are `Movies`, `movies`

For Web Series folder you can name are `Web Series`, `Web_Series`, `web_series`

For Music folder you can name are `Music`,`music`

```
/media
  /Movies
    movie.mp4
    /Movie Name
      movie.mp4

  /Web Series
    /Series Name
      /Season 1
        episode1.mp4
        episode2.mp4

  /Music
    song.mp3
    /Album
      song.mp3
```
